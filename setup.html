Lab Setup — your practice environment

Straight talk: no app can bundle a GPU. Real CUDA practice needs either NVIDIA hardware you own or a free cloud GPU. Both paths below are zero-cost to start; pick one now, add the other later. Module 1 needs no setup at all — start learning today, set this up before Module 2.

Path 1 — Google Colab (recommended start: free, zero install)

Colab gives you a real NVIDIA GPU (typically a T4) in the browser, free tier included. It runs Python, and — the part most beginners don't know — it compiles CUDA C++ too:

1. colab.research.google.com → New notebook
2. Runtime → Change runtime type → Hardware accelerator: GPU → Save
3. Verify the GPU:            !nvidia-smi
4. Python/PyTorch work now.   For CUDA C++ (Module 5 onward):

%%writefile hello.cu
#include <stdio.h>
__global__ void hello() { printf("Hello from GPU thread %d\n", threadIdx.x); }
int main() { hello<<<1, 8>>>(); cudaDeviceSynchronize(); return 0; }

!nvcc -arch=sm_75 hello.cu -o hello && ./hello
Free-tier realities: sessions time out (save work to Drive/GitHub), GPUs vary, and heavy use gets throttled. For this curriculum's exercises it's entirely sufficient through Module 5. Kaggle Notebooks are the backup free tier (30 h/week GPU quota, requires phone verification).

Path 2 — your own NVIDIA GPU (any GTX 10-series or newer works)

Windows: use WSL2 (the professional setup)

1. Install/update the NVIDIA *Windows* driver (that's the only driver you need)
2. PowerShell (admin):  wsl --install          # installs Ubuntu
3. Inside Ubuntu, install the CUDA TOOLKIT (13.x) — toolkit ≠ driver:
   follow developer.nvidia.com/cuda-downloads → Linux → x86_64 → WSL-Ubuntu
4. Verify:  nvidia-smi        (talks to the Windows driver)
            nvcc --version    (the compiler, from the toolkit)

Linux: native

Driver from your distro (ubuntu-drivers autoinstall) or NVIDIA's runfile,
toolkit from developer.nvidia.com/cuda-downloads. Keep driver ≥ toolkit's minimum.
Check both: nvidia-smi (driver + max CUDA it supports) vs nvcc --version (toolkit).
The #1 beginner confusion: nvidia-smi's "CUDA Version" is the max your driver supports; nvcc --version is what your toolkit compiles. They can differ. Kernels need toolkit ≤ driver's max. Second confusion: macOS has no CUDA at all (Apple GPUs speak Metal) — Mac owners use Colab for CUDA, and get a bonus: WebGPU work (Track D) runs natively in Safari 26+.
