The kernel (WGSL) — read it against CUDA

Two-level reduction: each workgroup grid-strides over its slice, reduces in var<workgroup> shared memory with a barrier tree (5.5/5.8), and writes one partial. The host sums the handful of partials. Note the one-to-one map: @workgroup_size is blockDim, workgroupBarrier() is __syncthreads(), var<workgroup> is __shared__.
