The Attention-Tiling Visualizer

Attention compares every token with every other token, so the score matrix it builds is N × N — and for a long sequence that matrix is far too big to keep in fast memory. FlashAttention is the trick that computes the exact same answer without ever storing the whole matrix, by sweeping it one tile at a time and carrying a running softmax. Watch the tiles light up, and watch the tiled output land bit-for-bit on the standard one.

How to read it

The grid is the attention score matrix: row i is a query, column j is a key, and each cell is how much token i attends to token j (brighter = more weight, after softmax). Standard attention computes the whole grid, writes all N² cells to memory, softmaxes each row, then multiplies by the values. That N² is the problem: double the sequence length and the matrix quadruples, and for real sequence lengths it will not fit in the on-chip memory that makes GPUs fast.

FlashAttention walks the grid one tile at a time. For each block of query rows it sweeps left to right across the key/value tiles, and for each tile it updates three small running quantities per query row: the running maximum m (so the exponentials never overflow — exactly the trick from the Softmax Stability lab), the running normalizer ℓ, and the output accumulator O, which is rescaled by exp(m_old − m_new) every time a bigger score appears. When the sweep of a row-block finishes, its output is already final and correct — and the full N² matrix was never stored. The memory cost drops from N² to O(N), which is why FlashAttention made long-context transformers practical.

The claim that matters is exactness: this is not an approximation. The running-softmax rescaling is algebraically identical to computing the whole row at once, so the tiled output equals the standard output to the last bit the hardware can represent — the badge above shows the measured difference on live random data, and it sits at the floating-point floor (~1e-16). Fast and exact is a rare combination; understanding why the rescale is exact (this lab, built on the softmax lab) is the core of Track A's Lesson A-series on attention.
