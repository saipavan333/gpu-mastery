The Module Generator Prompt

This prompt built Module 1 and will build every other module of this curriculum to the same standard. Paste it into a capable LLM (Claude, etc.), set the MODULE line, and attach or reference an existing lesson file so the model can mirror the exact HTML conventions.

How to use: ① Copy the prompt. ② Replace {{MODULE}} with a module/track ID from the curriculum (e.g. "Module 2: Programming from Zero" or "Track A, lessons A1–A3"). ③ Attach one existing lesson HTML (e.g. module-1/lesson-05.html) and assets/diagrams.js as style references. ④ Save the generated files into a new folder (module-2/…) and add links on the curriculum page.

Why this prompt is shaped this way

Three design choices carry the quality. Granular decomposition: each subtopic that could be an interview question is its own lesson — depth is impossible when a big topic is crammed into one page. The bar is behavioral: "could they do it on the job and defend it," which forces internals, trade-offs, gotchas, and a scenario into every lesson. Diagrams are unlimited but verified: visuals are added wherever they aid understanding — and each one must pass geometry checks and a human look before it ships, because a broken diagram teaches worse than none.
