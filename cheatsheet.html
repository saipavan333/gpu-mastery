Foundations Module 1

Bases & bits

  • 1 hex digit = 4 bits; 0x prefix. Byte = 2 hex digits.
  • Binary→dec: sum the weights of the 1-bits. Dec→binary: divide by 2, read remainders bottom-up.
  • Two's complement: negate = invert + 1; top bit is worth −2ⁿ⁻¹.
  • One adder handles all integers because of two's complement.

Ranges & magnitudes

int32 max2,147,483,647 (~2.1×10⁹)
uint32 max4,294,967,295
2¹⁰1,024 ≈ 10³ (KiB)
2²⁰ / 2³⁰≈ 10⁶ (MiB) / ≈ 10⁹ (GiB)

Floating point

FP321 sign · 8 exp · 23 mantissa (~7 dec digits)
FP161 · 5 · 10 — small range, overflows
BF161 · 8 · 7 — FP32 range, less precision
Specials±inf, NaN, subnormals, ±0
  • FP add is non-associative: parallel reductions vary run-to-run.

Linear algebra

  • Dot product: a·b = Σ aᵢbᵢ = |a||b|cosθ.
  • Matmul C[m,n] = Σₖ A[m,k]·B[k,n]; inner dims must match.
  • Matmul is O(n³) work, O(n²) data → high arithmetic intensity (GPU-friendly).

C, Pointers & Memory Module 3

Pointers

  • T* p; holds an address. *p dereferences; &x takes an address.
  • Pointer arithmetic: p + i advances by i × sizeof(T) bytes.
  • a[i] is *(a + i). Arrays decay to pointers.

Stack vs heap

  • Stack: automatic, fast, freed on return. Heap: malloc/free, manual, persists.
  • Leak = forgot free; use-after-free / double-free = UB.
  • CUDA mirrors this: cudaMalloc/cudaFree on the device heap.

Undefined behavior

  • Signed overflow = UB (compiler may assume it can't happen).
  • Unsigned wraps modulo 2ⁿ (defined).
  • Out-of-bounds, uninitialized reads, null deref = UB → segfaults.

Hardware & the Roofline Module 4

CPU vs GPU

  • CPU: few fat cores, big caches, out-of-order — latency.
  • GPU: many SMs × many ALUs, tiny per-thread state — throughput.
  • GPU hides memory latency by switching among many resident warps.

Memory hierarchy

Registersper-thread, fastest
Shared / L1per-SM, ~tens of KB, programmer-managed
L2device-wide cache
Global / HBMGBs, highest latency, the bottleneck

Roofline

  • Arithmetic intensity AI = FLOPs ÷ bytes moved.
  • Attainable = min(peak FLOP/s, AI × peak BW).
  • Ridge point = peak FLOP/s ÷ peak BW. Left = memory-bound; right = compute-bound.
  • Raise AI with reuse (tiling), fusion, better algorithms.

Host ↔ device

  • PCIe is slow vs HBM; NVLink is faster GPU↔GPU.
  • Use pinned host memory for fast, async DMA copies.
  • Overlap copy with compute using streams; minimize transfers.

CUDA Kernels Module 5

Launch & index

  • kernel<<<grid, block>>>(args); — grid = blocks, block = threads (max 1024/block).
  • int i = blockIdx.x*blockDim.x + threadIdx.x;
  • Grid-stride loop: for(; i<n; i += blockDim.x*gridDim.x) covers any size.

Qualifiers & memory

__global__kernel (host-launched)
__device__device-only function
__shared__per-block on-chip memory
__constant__cached read-only
cudaMalloc / cudaMemcpyalloc / H2D · D2H copy

Performance levers

  • Coalesce: consecutive threads → consecutive addresses.
  • Occupancy: capped by registers/thread, shared/block, threads/block. Enough > maximum.
  • Divergence: keep a warp on one branch path.
  • Shared-mem tiling; pad arrays to dodge 32-way bank conflicts.

Patterns & tools

  • Reduction: tree in shared mem + __shfl_down_sync for the last warp.
  • Contended writes: atomicAdd — but minimize contention.
  • Barrier: __syncthreads() (never in divergent code).
  • Debug: compute-sanitizer. Profile: ncu (kernel), nsys (timeline).

ML / AI Infrastructure Track A

Core ideas

  • Everything is GEMM — linear layers, attention, conv (im2col). Tensor cores accelerate mixed-precision MMA.
  • Autograd = reverse-mode chain rule; store activations for the backward pass.
  • Fusion keeps intermediates on-chip — the win for memory-bound ops.

Precision & attention

  • Mixed precision: compute FP16/BF16, keep FP32 master + accumulate; FP16 needs loss scaling.
  • FlashAttention: tile + online softmax; never materialize the N×N scores in HBM.

Scale-out

DDPreplicate model, all-reduce grads
FSDPshard params/opt state, gather JIT
NCCLtopology-aware collectives (all-reduce)

Inference & compile

  • KV cache makes decoding O(1)/token but dominates memory (batch×seq×layers×hidden).
  • Levers: quantization (INT8/INT4), batching, paged attention (vLLM).
  • torch.compile → TorchInductor → fused Triton kernels. Triton = block-level Python kernels.

Real-Time Graphics Track C

The pipeline

  • Vertex → primitive assembly → rasterize → fragment → framebuffer.
  • Homogeneous coords (x,y,z,w); Model·View·Projection; then perspective divide (÷w).

Shaders & textures

  • Vertex (transform), fragment (color), compute (general). GLSL → SPIR-V; WGSL on the web.
  • Textures: UV sampling, filtering, mipmaps for minification.

Lighting

  • Phong = ambient + diffuse (n·l) + specular.
  • PBR (Cook-Torrance): spec = D·G·F / (4·(n·l)(n·v)); GGX is the normal-distribution D.

Ray tracing & Vulkan

  • Ray tracing: ray–triangle hits accelerated by a BVH; shadows, reflections.
  • Vulkan is explicit: command buffers, barriers, semaphores/fences for sync.
  • Profile frames: RenderDoc, Nsight Graphics.

Cross-Vendor & Portable Track D

The landscape

CUDANVIDIA, most mature
HIP / ROCmAMD; hipify ports CUDA
SYCL / oneAPIIntel; single-source C++
OpenCLolder portable standard

Warp-size trap

  • NVIDIA warp = 32. AMD wavefront = 64 (GCN/CDNA) or 32 (RDNA).
  • Code hard-coding 32 (shuffles, lane masks) can break on 64-wide hardware.

Portability layers

  • Kokkos / RAJA: C++ templates, one source → many backends.
  • WebGPU / WGSL: modern GPU compute in the browser, zero install.
  • Triton / MLIR: compiler-based portability; lower ops through dialects.

Honest benchmarking

  • Warm up; time many iters; report medians + variance.
  • Compare like-for-like (same precision, same problem).
  • Watch for vendor-tuned libraries doing the real work.
