# Turning on AI answers for the Course Assistant

The assistant works **immediately with zero setup** in *offline mode*: it answers
every question by retrieving the most relevant lessons and glossary terms and
showing them with links. Nothing to deploy, no key, fully private.

This guide is only if you (the course owner) want **AI-written answers** — full
sentences generated by Google Gemini, grounded in your course — for every student,
with no key required on their side. It's free: the Gemini free tier has no card
attached, so you can never be charged.

---

## What you're building

```
Student's browser  ──POST {question, course context}──►  Your Cloudflare Worker  ──►  Google Gemini
        ▲                                                        │  (your API key lives here, as a secret)
        └───────────────────  { answer }  ◄─────────────────────┘
```

Your API key stays on the Worker as a secret — it is **never** shipped to the
website, so no one can read or steal it.

---

## Steps (about 10 minutes, all free)

### 1. Get a free Gemini API key
Go to <https://aistudio.google.com/apikey>, sign in, and create an API key. Copy it.

### 2. Create a free Cloudflare Worker
1. Sign up at <https://dash.cloudflare.com> (free).
2. **Workers & Pages → Create → Worker.** Give it a name, e.g. `gpu-assistant-proxy`.
3. **Edit code**, delete the template, and paste in the entire contents of
   [`worker/assistant-proxy.js`](./worker/assistant-proxy.js). Click **Deploy**.

### 3. Add your key as a secret
In the Worker's **Settings → Variables and Secrets**, add:

| Type      | Name              | Value                                             |
|-----------|-------------------|---------------------------------------------------|
| Secret    | `GEMINI_API_KEY`  | *your Gemini key from step 1*                     |
| Variable  | `GEMINI_MODEL`    | `gemini-flash-latest`  *(optional)*              |
| Variable  | `ALLOWED_ORIGINS` | `https://yourname.github.io`  *(optional, recommended)* |

`ALLOWED_ORIGINS` locks the Worker to your site (comma-separated for several;
leave blank to allow any origin). Re-deploy after adding variables.

### 4. Point the site at your Worker
Copy the Worker URL (looks like `https://gpu-assistant-proxy.yourname.workers.dev`)
and paste it into [`assets/assistant-config.js`](./assets/assistant-config.js):

```js
window.GM_ASSIST_PROXY = "https://gpu-assistant-proxy.yourname.workers.dev";
```

Commit and push. The assistant's footer will now read **"AI answers · from the
course lessons"** and answers will be written by Gemini, still linking to your lessons.

> **If answers error with "model not found":** the default `gemini-flash-latest`
> alias occasionally rotates. Set the `GEMINI_MODEL` variable to a concrete free
> model — `gemini-2.5-flash` (verified free-tier as of 2026) — and re-deploy.
> **Region note:** free-tier needs no card in most countries (incl. India); users
> in the EEA, UK, or Switzerland must enable billing even for the free models.

## Optional: see what students ask
In the Worker, bind a **KV namespace named `QLOG`** and set an `ADMIN_TOKEN`
variable. Then visit `https://<your-worker-url>/?admin=YOUR_ADMIN_TOKEN` to read
the most recent questions (auto-expire after 90 days). Leave `QLOG` unbound to
log nothing.

## Cost & privacy
- **Cost:** none. Free tier, no card. If the daily quota runs out, the assistant
  simply falls back to offline retrieval for the rest of the day.
- **Privacy:** questions pass through your Worker to Google. The offline mode
  (no Worker URL set) sends nothing anywhere.

## How it stays grounded
The Worker's system prompt instructs Gemini to answer **only** from the course
material passed with each question, to cite lessons by title, and to **ignore any
instructions inside that material** (prompt-injection defense). The website always
retrieves the relevant lessons first and shows them as sources under every answer.
